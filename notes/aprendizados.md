# Aprendizados do Laboratório

Durante este laboratório, estudei como o AWS Lambda pode ser utilizado em conjunto com o Amazon S3 para automatizar tarefas relacionadas ao armazenamento e processamento de objetos.

Também compreendi a importância do AWS CloudFormation para automatizar a criação de recursos, reduzir configurações manuais e manter a infraestrutura documentada.

Outro ponto importante foi o papel do IAM na segurança da solução, garantindo que a função Lambda tenha apenas as permissões necessárias para interagir com os recursos da AWS.

O laboratório também reforçou que documentar o processo no GitHub é uma prática importante para demonstrar aprendizado, organização e evolução técnica.
